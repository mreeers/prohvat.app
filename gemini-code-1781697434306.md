# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (PRD) — ВЕРСИЯ 2.0
## Проект: Экосистема и соцсеть для технического экстрима PROHVAT.APP

---

## 1. ОБЩЕЕ ОПИСАНИЕ И КОНЦЕПЦИЯ
Платформа представляет собой специализированную социальную сеть, гео-сервис и базу знаний для любителей внедорожной и трековой экстремальной техники (аналог Drive2, но адаптированный под жесткие условия эксплуатации).

### Ключевые столпы платформы:
1. **Сезонность:** Динамическая адаптация интерфейса и контента под текущее время года (Лето: Эндуро, Квадроциклы/ATV, Питбайки; Зима: Снегоходы, Зимний дрифт / Боевая Классика).
2. **Организация (Прохваты/Покатушки):** Инструмент для быстрого сбора групп, поиска маршрутов и спотов.
3. **Социальный слой (Бортжурналы):** Текстовые блоги, кастомизация, ремонты и интеграция коротких видеоотчетов.
4. **Безопасность и Экспертиза:** Система экстренного оповещения (SOS) в условиях частичного или полного отсутствия интернета и краудсорсинговая база взаимозаменяемости запчастей.

## 2. ТЕХНОЛОГИЧЕСКИЙ СТЕК И АРХИТЕКТУРА

### Бэкенд (Backend):
* **Платформа:** .NET 8 / .NET 9 (ASP.NET Core Web API).
* **Архитектура:** Clean Architecture + CQRS (библиотека `MediatR`) для изоляции команд (Command) и запросов (Query).
* **База данных:** PostgreSQL + PostGIS (гео-индексы `GiST` для пространственных данных).
* **ORM:** Entity Framework Core + `NetTopologySuite` (NTS).
* **Real-time слой:** `SignalR` (чаты рейда, real-time интерактивная карта покатушки, мгновенная обработка SOS-сигналов).

### Фронтенд (Frontend & Mobile):
* **Стек:** Vue 3 (Composition API) + TypeScript (строгая синхронизация типов и DTO с C# бэкендом).
* **Сборщик:** Vite.
* **Стейт-менеджер:** Pinia.
* **Картография:** Агностический слой-обертка карт через Leaflet.js / Mapbox.
* **Мобильная адаптация:** Capacitor (для сборки нативных мобильных приложений `.apk` и `.ipa` с доступом к Geolocation API, Camera API и Push-уведомлениям из единой кодовой базы Vue).

##4. СПЕЦИФИКАЦИЯ КИЛЛЕР-ФИЧ И ЛОГИКА РАБОТЫ
###4.1. Офлайн-режим и Кнопка SOS через SMS-шлюз
Сценарий: У пользователя в лесу/на треке пропал интернет (No-Service / Edge), но проходит экстренный сотовый сигнал.

Реализация: При нажатии кнопки "SOS" без сети, Capacitor-плагин генерирует сжатую текстовую строку: SOS_[UserId]_[Lat]_[Lng]_[Код_Проблемы]. Приложение вызывает нативный интерфейс отправки SMS на единый системный номер проекта.

Бэкенд: SMS-шлюз принимает и парсит входящее сообщение, создает инстанс SosSignal и через SignalR рассылает push/уведомления всем участникам активного рейда или райдерам в радиусе 15 км.

###4.2. Механика динамического Тюнинг-Конфига (Фронтенд + БД)
На фронтенде во Vue 3 при выборе категории "Жигули" стейт-менеджер Pinia считывает структуру полей из TechnicalConfigJson и рендерит специфичные селекторы ("Выворот подвески", "Гидроручник", "Заварка редуктора"). Для Эндуро — другие поля (тип карбюратора, защита).

Бэкенд индексирует JSON-B данные, позволяя делать пространственную выборку вида: «Найти все ВАЗ 2105 в радиусе 30 км с Красноярским выворотом».

###4.3. Автоматический расчет Системы Достижений (Ачивок)
Бэкенд-служба (BackgroundService) раз в сутки парсит контент новых записей в БЖ по триггерным словам (например, "гидроудар", "утопил", "залил"). При совпадении пользователю выдается ачивка "Утопленник".

При успешном завершении покатушки, если суммарный трек (GpxTrackPath) превышает 150 км, выдается ачивка "Железная задница".

##5. ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ (UI/UX СЕЗОННОСТЬ)
На уровне Vue 3 (Pinia) реализуется глобальный переключатель тем CurrentSeason.

Летний режим (Эндуро/ATV): Интерфейс окрашивается в теплые, грязно-оранжевые, хаки или матово-черные цвета. В приоритете списков — типы техники с метрикой "Моточасы".

Зимний режим (Снегоходы/Дрифт): Интерфейс переключается на холодные, неоново-синие, белые и серые тона. На главный экран выводятся дрифтовые споты и покатушки на снегоходах.

Архитектура фронтенда должна использовать Mobile-First подход: элементы управления картой, кнопка SOS и формы БЖ должны быть адаптированы под управление одной рукой.

##6. ЭТАПЫ РАЗВЕРТЫВАНИЯ ПРОДУКТА
Этап 1: MVP Core (1-3 мес)
Настройка PostgreSQL + PostGIS, EF Core миграций.

Авторизация (JWT), регистрация, создание профилей и сущностей Vehicle, Ride.

Реализация пространственного поиска покатушек вокруг пользователя через метод PostGIS ST_DWithin.

Написание Vue 3 SPA + Vite + Pinia с интеграцией карт Leaflet.js.

Этап 2: Социализация и Тюнинг (3-5 мес)
Полноценная лента Бортжурналов с возможностью загрузки фото и ссылок на видео в S3/MinIO.

Сущность PartReview (краудсорсинг запчастей) и динамические JSON-конфиги для дрифта и эндуро.

Интеграция Capacitor для сборки базовых .apk и .ipa пакетов.

Этап 3: Безопасность и Геймификация (5-6 мес)
Подключение SMS-шлюза для парсинга офлайн-SOS сигналов.

Запуск SignalR хаба для real-time трекинга гео-позиции участников во время рейда.

Модуль ачивок, геймификации и оптимизация производительности мобильных версий.
